# 06. 실험 설계

## 질문

**같은 시간을 들였을 때, 처음부터 시연을 더 하는 것과 틀린 부분만 손으로 바로잡는 것 중 어느 쪽이 로봇 성공률을 더 올리는가?**

## 과제

- SO-101(MuJoCo)로 블록(약 3cm)을 집어 표시된 목표 위에 놓기
- 블록·목표 위치는 시드로 정함. 시연용 시드와 평가용 시드는 겹치지 않게
- 성공: 블록이 목표 영역 안에 놓이고 그리퍼가 열린 상태로 일정 시간 안에 끝남 (기준은 녹화 전에 고정)

## 조건

| 이름 | 데이터 | 설명 |
|---|---|---|
| 기본 (v1) | 시연 20개 | 모든 조건의 출발점 |
| A: 추가 시연 | 시연 20개 + 추가 시연 **T분** | 실패하면 처음부터 다시 보여주는 기존 방식 |
| B: 교정 | 시연 20개 + 교정 **T분** | v1을 돌리며 틀린 순간만 바로잡음 (HUMAN 구간만 학습) |

- **T는 같게** 한다(예: 10분). 시간은 사람이 손을 쓴 시간 기준으로 기록.
- A와 B를 번갈아 녹화해서 연습 효과(뒤로 갈수록 잘하는 것)를 섞는다.
- 학습 설정(ACT 기본값, 학습 스텝)은 모든 조건에서 같게.

## 측정

| 지표 | 방법 |
|---|---|
| 성공률 | 평가 시드 50~100개에서 성공 비율. 가능하면 학습 시드 3개 평균 |
| 사람 시간 | 조건별 실제로 손을 쓴 시간 |
| 교정 횟수·길이 | B에서 넘겨받은 횟수, 평균 몇 초 |
| 실패 유형 | 집기 실패 / 옮기다 떨어뜨림 / 목표 빗나감 — 어디서 많이 틀리는지 |
| 조종 지연 | 손 움직임 → 화면 반영 시간 (2단계) |

## 결과 기록

- 숫자는 `experiments/`에 CSV로. 웹캠 영상은 저장하지 않는다.
- 결과가 기대와 다르게 나와도 그대로 쓴다(예: "B가 A보다 낮았다, 이유는 ~로 추정"). 작은 실험이라 차이가 우연일 수 있다는 점을 같이 적는다.
